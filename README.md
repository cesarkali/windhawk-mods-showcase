## 🏝️ Mac Island & Dock

An island at the top of the screen like the macOS menu bar and the iPhone's Dynamic Island (clock, control center, notifications, media, tray icons), and a macOS-like dock instead of the taskbar.

![The island opening from its line, a timer going, the media panel and its mixer](https://i.imgur.com/27R6hST.gif)

|:---:|:---:|

## 🖥️ Windows Terminal Start Minimized

When Windows Terminal opens at sign-in, it starts minimized or straight in the notification area. Requires Terminal's "Launch on machine startup" option.

**[Install on Windhawk →](https://windhawk.net/mods/windows-terminal-start-minimized)** · [Source code](https://github.com/ramensoftware/windhawk-mods/blob/main/mods/windows-terminal-start-minimized.wh.cpp)

## How to install

1. Install [Windhawk](https://windhawk.net) (free).
2. Open the mod's link above and click **Install**, or search its name in Windhawk's **Explore** tab.

## Bugs and ideas

Issues are turned off here on purpose. Please open an issue in [ramensoftware/windhawk-mods](https://github.com/ramensoftware/windhawk-mods/issues) with the mod's name in the title, so everything stays in one place.
